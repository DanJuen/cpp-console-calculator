# C++ Taschenrechner

Ein einfacher Konsolen-Taschenrechner, den ich mit C++ und Visual Studio entwickle. Das Projekt dient dazu, meine Kenntnisse in der C++-Programmierung praktisch aufzubauen und zu vertiefen.

## Funktionen

- Grundrechenarten: Addition, Subtraktion, Multiplikation und Division
- Eingabe von Zahlen über die Konsole
- Auswahl der Rechenoperation über einen Operator
- Behandlung ungültiger Eingaben
- Prüfung auf Division durch null
- Möglichkeit, mehrere Berechnungen hintereinander auszuführen
- Aufteilung des Programms in mehrere Funktionen und Quelldateien
- Fehlerbehandlung mithilfe von Exceptions (try, catch, throw)

## Technologien

- C++
- Visual Studio
- Git und GitHub zur Versionsverwaltung
